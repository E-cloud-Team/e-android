# e 安卓客户端

[e](https://harnesshub.me) 的安卓应用：浏览动态、帖子、软件与私信，网站链接直接在应用中打开，有新版本时自动提示。

## 下载

- 最新版（GitHub）：<https://github.com/E-cloud-Team/e-android/releases/latest/download/e.apk>
- 国内镜像：<https://harnesshub.me/assets/app/e.apk>
- 历史版本：[Releases](https://github.com/E-cloud-Team/e-android/releases)

要求 Android 7.0 及以上。首次安装时，系统会提示允许浏览器“安装未知应用”。

## 校验

每个 Release 的说明里都附有 SHA-256；签名证书指纹：

```
6F:36:15:FF:CF:76:E2:22:C5:E5:F5:D3:99:7A:CB:92:24:97:10:FA:9B:7C:26:01:37:89:BE:3F:6C:AE:ED:0D
```

本仓库只存放发布的安装包；推送新的 `e.apk` 与 `version.json` 后，Actions 会自动创建对应版本的 Release。
